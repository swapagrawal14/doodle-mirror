# Start here (on your laptop)

1. **Install Kiro** from kiro.dev/downloads and sign in.
2. **Get the repo:**
   `git clone https://github.com/swapagrawal14/doodle-mirror.git`
   then in Kiro: File → Open Folder → `doodle-mirror`.
3. **Credits:** when the Kiroween credits code arrives by email, redeem it in Kiro (account / billing page).
4. **Check the Kiro panel:** you should see 4 steering files, 1 spec and 2 hooks. Turn the hooks on if they are off.
5. **Open the spec:** `.kiro/specs/doodle-mirror/` → read requirements, then design, then open `tasks.md`.
6. **Run the tasks in order:** click "Start task" on task 1, review what Kiro wrote, accept, then task 2, and so on. Commit after each task.
7. **Test as you go:** `npm run dev`, allow the camera, try all 8 poses. Press `D` for the debug view.
8. **Take screenshots** of the spec, hooks firing and Kiro chats for the README's "Built with Kiro" section and the Devpost video.
9. **Deploy:** import the repo on vercel.com, then add the live link to README and Devpost.

Tip: if a pose looks wrong, tell Kiro to tune `src/config.ts`, never to add puppet limbs.
